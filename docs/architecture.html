Architecture Overview

Factory Inventory Management System

A full-stack inventory and order management demo: a Vue 3 single-page app talking to a FastAPI backend that serves data from in-memory JSON files — no database.

Vue 3 Vite FastAPI Pydantic Python No Database

Tech Stack

Two independent processes: a Vite dev server for the SPA and a Uvicorn/FastAPI process for the API.

Frontend — port 3000
  • Vue 3 — Composition API, Options-style export default (no <script setup>)
  • Vite — dev server and build tool
  • vue-router — client-side routing across views
  • axios — HTTP client, centralized in a single api.js
  • Composables — hand-rolled singleton state (no Vuex/Pinia)
  • Charts — hand-built inline SVG / CSS, no charting library
Backend — port 8001
  • FastAPI — single-module app (main.py), no routers/services split
  • Uvicorn — ASGI server, run directly via uv run python main.py
  • Pydantic — response validation/serialization only, not storage
  • CORS middleware — wide open (dev-only), no auth layer
  • In-memory data — JSON files loaded once at startup into Python lists
  • Read-only API — every route is a GET; no writes persist

Notable Design Notes

No database

7 JSON files under server/data/ are the entire "database," loaded once into memory at startup.

Read-only API

Every route is a GET. Nothing written by the app persists past a server restart.

No global state library

Filter state is a hand-rolled composable singleton (module-scoped refs) instead of Vuex/Pinia.

Flat backend

All routes and models live in one main.py — no routers, services, or ORM layer.
